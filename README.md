# 🥋 DindonBahia — Associação de Capoeira

Site institucional responsivo desenvolvido para a **Associação de Capoeira DindonBahia**, com o objetivo de ampliar a divulgação das atividades e facilitar o contato com novos alunos.

---

## 🚀 Tecnologias Utilizadas

| Tecnologia | Finalidade |
|------------|------------|
| HTML5 | Estrutura e semântica do site |
| CSS3 | Estilização, layout e responsividade |

---

## ✨ Funcionalidades

- 📱 Design responsivo — compatível com celular, tablet e desktop
- 🧭 Navegação simples e bem organizada
- 🔗 Integração com redes sociais
- 🍔 Menu adaptado para dispositivos móveis
